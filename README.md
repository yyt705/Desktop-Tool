# DeskFences - 轻量液态玻璃桌面分区

一个超轻量的 Windows 桌面图标分区管理工具（64 位单文件，无需安装，零依赖）。

## 核心特性

- **不改动任何文件目录，100% 保留原生桌面体验**：不复制图标、不修改任何真实文件路径，框内与框外的点击、双击、框选、拖拽、右键菜单与 Windows 原生桌面完全一致。
- **实时穿透液态玻璃（兼容 Wallpaper Engine）**：
  - 分区底板精准嵌入壁纸与桌面图标夹层，采用微磨砂液态玻璃质感（含顶部弧面反光、细腻磨砂颗粒与方向性玻璃高光边缘），支持 **Wallpaper Engine 动态壁纸 / 视频 / 原生壁纸** 实时穿透显示。
  - 内置 5 套液态玻璃风格与多档通透度调节。
- **四边独立预留网格 + 严格手动归属规则**：
  - 每个分区的四条边各占 1 行/1 列独立图标位，相邻外部图标可紧贴分区摆放而绝不重叠；放入四条边上的图标会自动移出到分区外。
  - 手动拖入或拖出图标可以改变归属（支持多选、跨窗口直接从文件夹拖入分区，以及分区内右键新建/粘贴）。新增桌面外部文件会自动避让所有分区。
  - 响应 Windows “隐藏桌面图标”状态，也可通过托盘菜单一键显隐所有分区边框。
- **零闪烁刚体拖拽与智能缩放**：
  - 拖动标题栏时，分区与内部图标整体丝滑跟随移动，不会将成员图标临时暴露到分区外桌面；松手若与其他分区重叠，会以橙色边框提示并自动就近滑入最近的无重叠空位，落点处的外部图标会自动驱离避让。
  - 缩小分区时自动保护内部成员图标并同步内推，确保不会将框内图标挤出分区；支持对单个分区内部图标一键紧凑排序。

## 快捷操作

直接双击运行 `DeskFences.exe`：
- **拖动标题栏**：按桌面网格整体移动分区与框内图标
- **双击标题栏**：原地重命名分区
- **拖动四边 / 四角**：按桌面网格缩放分区大小
- **右键标题栏 / 点 `⋯`**：重命名分区、整理此分区图标（按名称 / 类型 / 修改时间）、切换液态玻璃风格、调节玻璃通透度、新建 / 框选新建（带实时网格预览）/ 删除分区
- **双击或右键托盘图标**：框选桌面区域新建分区、新建桌面分区、锁定所有分区位置与大小、隐藏所有分区边框、开机自动启动

重新编译：
```powershell
.\build.ps1
```

布局保存在程序旁的 `fences_config.json`。首次保存旧版布局时，程序会将原文件备份为 `fences_config.legacy.json`，并把可识别的桌面图标迁移到新的成员记录。同名图标按实际桌面项区分。配置暂时无法写入时，托盘会提示并自动重试。

运行隔离回归测试：

```powershell
.\tests\run.ps1
```
